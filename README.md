# Live Time — World Clock

A responsive live clock web app built with HTML, CSS, and vanilla JavaScript.

## Features
- Live clock updates every second
- Select from 10 world time zones
- Switch between 12-hour and 24-hour formats
- Live quick clocks for New York, London, and Tokyo
- Responsive layout for desktop and mobile
- Uses the browser's built-in `Intl.DateTimeFormat` time-zone support

## Run
Open `index.html` in any modern browser. No installation or server is required.
